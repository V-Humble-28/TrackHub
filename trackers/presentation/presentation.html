DevOps Architecture Highlights

Key design principles implemented across TrackHub for the DevOps examination.

1. API Gateway Pattern

Centralized Flask gateway (app.py) on port 5001 mounts decoupled tracker route maps, manages global CORS, and routes static assets.

2. Data Isolation (4 SQLite DBs)

Each tracker owns its local database (calorie.db, expenses.db, etc.) eliminating cross-module schema locking and database contention.

3. GitHub Flow & Atomic Commits

100% of features developed on short-lived branches and merged via Pull Requests (PRs #1 to #12) with Conventional Commits.
